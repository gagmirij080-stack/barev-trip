# Инструкция: Превращение макета Barev.trip в полноценный WordPress-сайт

Этот пакет содержит всё необходимое, чтобы развернуть сайт **barev.trip** на WordPress на профессиональном уровне.

## 1. Что входит в проект
- **`index.html`** — современный премиальный макет туристического сайта (который вы только что видели). Вы можете показать его клиентам или использовать как визуальный ориентир.
- **Темы WordPress** (`the-fundraiser.zip`, `wens-vista.zip`) — скачаны и готовы к установке в разделе **Appearance > Themes**.

## 2. Как превратить это в идеальный WordPress-сайт (Пошаговый план)

Чтобы сайт работал на движке WordPress (с админкой, базой данных и возможностью бронирования туров):

### Шаг 1: Развертывание WordPress
1. Установите **LocalWP** (localwp.com) или поднимите сайт на вашем хостинге.
2. Создайте сайт с именем **barev-trip**.

### Шаг 2: Установка темы
1. Зайдите в админку WordPress (`/wp-admin`).
2. Перейдите в **Appearance > Themes > Add New > Upload Theme**.
3. Загрузите тему **Wens Vista** (`wens-vista.zip`) или **The Fundraiser** (`the-fundraiser.zip`), активируйте её.

### Шаг 3: Установка ключевых плагинов для туризма
Чтобы сайт не уступал лучшим туроператорам, установите следующие бесплатные плагины через **Plugins > Add New**:
- **WP Travel** или **Masteriyo / Tourfic** — превращает WordPress в полноценную систему бронирования туров (с датами, ценами, выбором участников и оформлением заказа).
- **Elementor** (или Gutenberg) — визуальный конструктор страниц, с помощью которого вы сможете перенести дизайн из нашего макета (`index.html`) в блоки WordPress без написания кода.
- **Contact Form 7** — для формы обратной связи и заявок.
- **Polylang** — для добавления армянского, русского и английского языков (как в проекте Tonavia).

### Шаг 4. Наполнение турами
Создайте туры через созданный плагином пункт меню (например, *Tours > Add New*):
1. **Храм Гарни и пещерный Гегард** (15,000 ֏)
2. **Озеро Севан и Севанаванк** (18,000 ֏)
3. **Хор Вирап и панорама Арарата** (16,000 ֏)
4. **Легенды Сюника и Крылья Татева** (45,000 ֏)
5. **Армянская Швейцария — Дилижан** (20,000 ֏)
6. **Винный тур в Арени и Нораванк** (22,000 ֏)

После этого сайт готов к подключению домена и реального хостинга!
