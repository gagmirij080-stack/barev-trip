# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | ✅ |

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Write to **hello@barevtrip.am** with:

- a short description of the issue and its impact;
- the URL or file concerned;
- steps to reproduce, if applicable.

You can expect an acknowledgement within 72 hours. Please allow time for a fix before any public disclosure.

## Scope

This repository hosts a static website (GitHub Pages). There is no server-side code, no database and no user accounts, so the most relevant risks are third-party script/CDN compromise and content injection through the repository itself.
