# AI Travel Agent: Barev.trip Smart Assistant

Этот продвинутый агент (`agent.py`) разработан специально для туристического проекта **Barev.trip**. Он автоматизирует взаимодействие с клиентами, подбирает туры на основе интересов и рассчитывает стоимость поездок.

## Основные возможности агента:
1. **Многоязычное приветствие:** Приветствует клиентов на армянском (`hy`), русском (`ru`) или английском (`en`) языках.
2. **Интеллектуальный подбор туров (`recommend_tour`):**
   - По интересам: история и культура, природа и озера, гастрономия и винные туры.
3. **Калькулятор стоимости (`calculate_trip_cost`):**
   - Учитывает количество участников, выбранный тур и опциональное добавление отеля.

## Как запустить агента:
```bash
python agent.py
```
